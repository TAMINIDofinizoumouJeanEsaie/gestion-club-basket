# Gestion du club de basket (BIT Basket Club)

Projet de groupe de Programmation Orientée Objet, BIT 2e année. Java 17, Maven, JUnit 5.

## Lancer
    mvn clean test
    mvn clean package -DskipTests
    java -cp target/classes club.ui.Main

## Rejouer la démonstration
    java -cp target/classes club.ui.Main < docs/demo_saisie.txt

Supprimer ensuite le dossier donnees/ créé par la démo.
